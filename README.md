# 📘 Livro Prático de Desenvolvimento de APIs REST com Python e FastAPI

### *Aprenda construindo uma aplicação real do início ao fim.*

---

## 👋 Seja bem-vindo!

Este repositório contém o material completo do **Livro Prático de Desenvolvimento de APIs REST com Python e FastAPI**.

Ao longo desta jornada você aprenderá a desenvolver uma API REST moderna utilizando **Python**, **FastAPI**, **SQLAlchemy**, **MySQL**, **Docker**, **Git** e diversas outras tecnologias amplamente utilizadas no mercado.

Mais do que apresentar comandos e trechos de código, este livro foi escrito para explicar **o motivo de cada decisão**, permitindo que você compreenda como cada componente participa da construção de uma aplicação profissional.

Nosso objetivo é que, ao concluir a leitura, você seja capaz de desenvolver seus próprios projetos utilizando uma arquitetura organizada, escalável e de fácil manutenção.

---

# 📖 Sobre este livro

Este não é um livro baseado apenas em teoria.

Durante toda a leitura construiremos, passo a passo, uma aplicação completa que evoluirá capítulo após capítulo.

Cada novo conceito será aplicado imediatamente em um projeto real, permitindo que você acompanhe a evolução da aplicação desde a criação do ambiente de desenvolvimento até sua publicação.

Sempre que um novo recurso for apresentado, você entenderá:

- Por que ele existe.
- Qual problema ele resolve.
- Como ele funciona.
- Como utilizá-lo na prática.

Nosso foco é desenvolver não apenas a habilidade de escrever código, mas também a capacidade de compreender as decisões tomadas durante o desenvolvimento de um software.

---

# 🏫 Projeto de Referência

Durante todo o livro construiremos um **Sistema de Gestão Escolar**.

Este projeto foi escolhido por apresentar diversas situações comuns ao desenvolvimento de sistemas corporativos, permitindo explorar desde operações básicas de cadastro até recursos mais avançados, como autenticação, documentação automática, upload de arquivos e implantação da aplicação.

Embora o domínio utilizado seja um sistema escolar, toda a arquitetura apresentada poderá ser reutilizada em outros tipos de sistemas, como:

- Clínicas médicas
- Academias
- Restaurantes
- Hotéis
- Pet Shops
- Bibliotecas
- Imobiliárias
- Sistemas comerciais
- E-commerce
- Entre muitos outros.

Nosso objetivo não é ensinar apenas um projeto específico, mas apresentar uma base sólida para o desenvolvimento de qualquer API REST.

# 🎯 Nossa filosofia

Este livro foi construído seguindo alguns princípios fundamentais.

## Aprender entendendo

Antes de apresentar qualquer ferramenta, primeiro explicaremos qual problema ela resolve.

---

## Aprender fazendo

Todo conceito apresentado será aplicado imediatamente em uma atividade prática.

---

## Evolução gradual

Nenhum conhecimento será considerado obrigatório.

Sempre que um novo assunto for apresentado, ele será explicado desde seus fundamentos.

---

## Clareza acima da complexidade

Sempre que existir uma maneira mais simples de explicar um conceito, ela será utilizada.

Nosso objetivo é tornar assuntos complexos acessíveis sem perder a precisão técnica.

---

## Construção contínua

A aplicação desenvolvida evoluirá ao longo do livro.

Cada capítulo acrescentará uma nova funcionalidade ao projeto, simulando a evolução natural de um software desenvolvido em um ambiente profissional.

# 📚 Como utilizar este livro

A recomendação é que os capítulos sejam estudados na ordem em que foram escritos.

Os primeiros capítulos apresentam os conceitos fundamentais necessários para compreender os capítulos seguintes.

Quando um capítulo depender de conhecimentos anteriores, isso será indicado no início do texto.

Caso deseje apenas consultar um determinado assunto, os capítulos conceituais poderão ser lidos de forma independente.
